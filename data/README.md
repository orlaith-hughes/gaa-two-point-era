# Data dictionary: mayo_2026_matches.csv

One row per Mayo match in the 2026 All-Ireland Senior Football Championship.

| Column | Meaning |
|---|---|
| match_no | Order the match was played in |
| date | Match date (YYYY-MM-DD) |
| stage | Competition round |
| opponent | Team Mayo played |
| venue | Ground |
| mayo_goals / mayo_points | Mayo's scoreline, e.g. 1-20 = 1 goal, 20 points |
| opp_goals / opp_points | Opponent's scoreline |
| mayo_2pt_made | Two-pointers Mayo scored |
| mayo_2pt_attempts | Mayo shots from outside the 40m arc (blank if not reported) |
| opp_2pt_made | Two-pointers the opponent scored |
| result | W = win, L = loss, D = draw |

Sources: official match reports from gaa.ie, hoganstand.com, Irish Examiner and Irish Times.
Note: two-pointers are already included in the points column.
